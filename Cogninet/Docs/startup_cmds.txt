Terminal 1 — Backend
cd ~/Desktop/VII-Network-Management-System/Cogninet/backend
mvn spring-boot:run

Wait until you see that Spring Boot has started on port 8080.
Terminal 2 — GNS3 Server
gns3server --host 127.0.0.1 --port 3080

Keep this terminal running.
Terminal 3 — GNS3 Application
Open another terminal:
gns3

Then:
1. Open Cogninet-Network
2. Make sure R1, R2 and R3 are running
3. Make sure the links are connected:
R1 eth0 ─── R2 eth0
R1 eth1 ─── R3 eth0
R2 eth1 ─── R3 eth1

4. Make sure R1 eth1 is UP
5. Do not inject any fault yet.
Your starting topology should be:
             R1
            /  \
           /    \
         R2──────R3
